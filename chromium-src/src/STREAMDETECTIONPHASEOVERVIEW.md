 # DataSipper Stream Detection - Phase 6 Plan                                                                                                                                                                   
                                                                                                                                                                                                                
 **Phase:** Stream Registry                                                                                                                                                                                     
 **Effort:** 3-4 days                                                                                                                                                                                           
 **Priority:** High (foundational for phases 7-9)                                                                                                                                                               
 **Status:** Not started                                                                                                                                                                                        
                                                                                                                                                                                                                
 ## Overview                                                                                                                                                                                                    
                                                                                                                                                                                                                
 Phase 6 implements a central StreamRegistry that manages all detected streams across the browser. This registry serves as the single source of truth for stream state, enables deduplication, manages          
 subscriptions, and provides a clean API for accessing stream data.                                                                                                                                             
                                                                                                                                                                                                                
 ## Goals                                                                                                                                                                                                       
                                                                                                                                                                                                                
 1. **Central Stream Management**: Single registry for all streams (DOM + network)                                                                                                                              
 2. **Deduplication**: Prevent duplicate streams across tabs                                                                                                                                                    
 3. **Subscription Management**: Track which workflows/tabs subscribe to streams                                                                                                                                
 4. **State Persistence**: Maintain stream state in memory                                                                                                                                                      
 5. **Pattern Matching**: Match streams to workflow subscriptions                                                                                                                                               
 6. **Lifecycle Management**: Handle stream activation/deactivation

 std::string StreamRegistry::RegisterStream(const StreamDefinition& stream) {                                                                                                                                   
   // Check for duplicates first                                                                                                                                                                                
   std::optional<std::string> existing_id = FindDuplicateStream(stream);                                                                                                                                        
   if (existing_id.has_value()) {                                                                                                                                                                               
     LOG(INFO) << "Stream already registered: " << existing_id.value();                                                                                                                                         
     // Update the existing stream instead                                                                                                                                                                      
     UpdateStream(existing_id.value(), stream);                                                                                                                                                                 
     return existing_id.value();                                                                                                                                                                                
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   // Create managed stream                                                                                                                                                                                     
   ManagedStream managed;                                                                                                                                                                                       
   managed.definition = stream;                                                                                                                                                                                 
   managed.registered_at = base::Time::Now();                                                                                                                                                                   
   managed.last_update = base::Time::Now();                                                                                                                                                                     
   managed.is_active = stream.is_active;                                                                                                                                                                        
   managed.event_count_total = 0;                                                                                                                                                                               
                                                                                                                                                                                                                
   // Store with stream_id as key                                                                                                                                                                               
   std::string stream_id = stream.stream_id;                                                                                                                                                                    
   streams_[stream_id] = std::move(managed);                                                                                                                                                                    
                                                                                                                                                                                                                
   // Index for pattern matching                                                                                                                                                                                
   IndexStreamPattern(stream_id, stream);                                                                                                                                                                       
                                                                                                                                                                                                                
   LOG(INFO) << "✅ StreamRegistry: Registered stream " << stream_id                                                                                                                                             
             << " (total: " << streams_.size() << ")";                                                                                                                                                          
                                                                                                                                                                                                                
   return stream_id;                                                                                                                                                                                            
 }                                                                                                                                                                                                              
 ```                                                                                                                                                                                                            
                                                                                                                                                                                                                
 #### 2. PublishEvent                                                                                                                                                                                           
 ```cpp                                                                                                                                                                                                         
 void StreamRegistry::PublishEvent(const std::string& stream_id,                                                                                                                                                
                                    const base::Value& data,                                                                                                                                                    
                                    const std::string& event_type) {                                                                                                                                            
   auto it = streams_.find(stream_id);                                                                                                                                                                          
   if (it == streams_.end()) {                                                                                                                                                                                  
     LOG(WARNING) << "Attempted to publish to unknown stream: " << stream_id;                                                                                                                                   
     return;                                                                                                                                                                                                    
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   ManagedStream& managed = it->second;                                                                                                                                                                         
                                                                                                                                                                                                                
   // Create event                                                                                                                                                                                              
   StreamEvent event;                                                                                                                                                                                           
   event.stream_id = stream_id;                                                                                                                                                                                 
   event.timestamp = base::Time::Now();                                                                                                                                                                         
   event.data = data.Clone();                                                                                                                                                                                   
   event.event_type = event_type;                                                                                                                                                                               
                                                                                                                                                                                                                
   // Add to recent events buffer (ring buffer)                                                                                                                                                                 
   managed.recent_events.push_back(event);                                                                                                                                                                      
   if (managed.recent_events.size() > ManagedStream::kMaxRecentEvents) {                                                                                                                                        
     managed.recent_events.pop_front();                                                                                                                                                                         
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   // Update statistics                                                                                                                                                                                         
   managed.event_count_total++;                                                                                                                                                                                 
   managed.last_update = event.timestamp;                                                                                                                                                                       
                                                                                                                                                                                                                
   // Notify all subscribers                                                                                                                                                                                    
   NotifySubscribers(stream_id, event);                                                                                                                                                                         
                                                                                                                                                                                                                
   DVLOG(2) << "📊 StreamRegistry: Published event to " << stream_id                                                                                                                                            
            << " (subscribers: " << GetSubscriberCount(stream_id) << ")";                                                                                                                                       
 }                                                                                                                                                                                                              
 ```                                                                                                                                                                                                            
                                                                                                                                                                                                                
 #### 3. Subscribe                                                                                                                                                                                              
 ```cpp                                                                                                                                                                                                         
 std::string StreamRegistry::Subscribe(                                                                                                                                                                         
     const std::string& stream_id,                                                                                                                                                                              
     StreamEventCallback callback,                                                                                                                                                                              
     const StreamSubscriptionOptions& options) {                                                                                                                                                                
                                                                                                                                                                                                                
   // Verify stream exists                                                                                                                                                                                      
   if (streams_.find(stream_id) == streams_.end()) {                                                                                                                                                            
     LOG(ERROR) << "Cannot subscribe to unknown stream: " << stream_id;                                                                                                                                         
     return "";                                                                                                                                                                                                 
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   // Create subscriber                                                                                                                                                                                         
   Subscriber subscriber;                                                                                                                                                                                       
   subscriber.subscriber_id =                                                                                                                                                                                   
       "sub_" + stream_id + "_" + std::to_string(next_subscription_id_++);                                                                                                                                      
   subscriber.stream_id = stream_id;                                                                                                                                                                            
   subscriber.callback = std::move(callback);                                                                                                                                                                   
   subscriber.options = options;                                                                                                                                                                                
   subscriber.subscribed_at = base::Time::Now();                                                                                                                                                                
   subscriber.events_received = 0;                                                                                                                                                                              
   subscriber.last_event_time = base::Time::Min();                                                                                                                                                              
                                                                                                                                                                                                                
   // Backfill recent events if requested                                                                                                                                                                       
   if (options.include_recent_events && options.recent_event_count > 0) {                                                                                                                                       
     std::vector<StreamEvent> recent = GetRecentEvents(                                                                                                                                                         
         stream_id, options.recent_event_count);                                                                                                                                                                
     for (const auto& event : recent) {                                                                                                                                                                         
       subscriber.callback.Run(event);                                                                                                                                                                          
       subscriber.events_received++;                                                                                                                                                                            
     }                                                                                                                                                                                                          
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   std::string subscription_id = subscriber.subscriber_id;                                                                                                                                                      
   subscribers_[subscription_id] = std::move(subscriber);                                                                                                                                                       
                                                                                                                                                                                                                
   LOG(INFO) << "✅ StreamRegistry: Subscribed " << subscription_id                                                                                                                                              
             << " to stream " << stream_id;                                                                                                                                                                     
                                                                                                                                                                                                                
   return subscription_id;                                                                                                                                                                                      
 }                                                                                                                                                                                                              
 ```                                                                                                                                                                                                            
                                                                                                                                                                                                                
 #### 4. NotifySubscribers                                                                                                                                                                                      
 ```cpp                                                                                                                                                                                                         
 void StreamRegistry::NotifySubscribers(const std::string& stream_id,                                                                                                                                           
                                         const StreamEvent& event) {                                                                                                                                            
   std::vector<std::string> to_remove;                                                                                                                                                                          
                                                                                                                                                                                                                
   for (auto& [sub_id, subscriber] : subscribers_) {                                                                                                                                                            
     if (subscriber.stream_id != stream_id) {                                                                                                                                                                   
       continue;                                                                                                                                                                                                
     }                                                                                                                                                                                                          
                                                                                                                                                                                                                
     // Check if event should be delivered                                                                                                                                                                      
     if (!ShouldDeliverEvent(subscriber, event)) {                                                                                                                                                              
       continue;                                                                                                                                                                                                
     }                                                                                                                                                                                                          
                                                                                                                                                                                                                
     // Deliver event                                                                                                                                                                                           
     subscriber.callback.Run(event);                                                                                                                                                                            
     subscriber.events_received++;                                                                                                                                                                              
     subscriber.last_event_time = event.timestamp;                                                                                                                                                              
                                                                                                                                                                                                                
     // Check if subscriber hit limits                                                                                                                                                                          
     if (subscriber.options.max_events.has_value() &&                                                                                                                                                           
         subscriber.events_received >= subscriber.options.max_events.value()) {                                                                                                                                 
       to_remove.push_back(sub_id);                                                                                                                                                                             
       LOG(INFO) << "StreamRegistry: Auto-unsubscribing " << sub_id                                                                                                                                             
                 << " (max events reached)";                                                                                                                                                                    
     }                                                                                                                                                                                                          
                                                                                                                                                                                                                
     if (subscriber.options.max_duration.has_value()) {                                                                                                                                                         
       base::TimeDelta elapsed =                                                                                                                                                                                
           base::Time::Now() - subscriber.subscribed_at;                                                                                                                                                        
       if (elapsed >= subscriber.options.max_duration.value()) {                                                                                                                                                
         to_remove.push_back(sub_id);                                                                                                                                                                           
         LOG(INFO) << "StreamRegistry: Auto-unsubscribing " << sub_id                                                                                                                                           
                   << " (max duration reached)";                                                                                                                                                                
       }                                                                                                                                                                                                        
     }                                                                                                                                                                                                          
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   // Remove subscribers that hit limits                                                                                                                                                                        
   for (const auto& sub_id : to_remove) {                                                                                                                                                                       
     Unsubscribe(sub_id);                                                                                                                                                                                       
   }                                                                                                                                                                                                            
 }                                                                                                                                                                                                              
 ```

     const StreamDefinition& stream) const {                                                                                                                                                                    
                                                                                                                                                                                                                
   for (const auto& [stream_id, managed] : streams_) {                                                                                                                                                          
     const StreamDefinition& existing = managed.definition;                                                                                                                                                     
                                                                                                                                                                                                                
     // Same stream ID = duplicate                                                                                                                                                                              
     if (existing.stream_id == stream.stream_id) {                                                                                                                                                              
       return stream_id;                                                                                                                                                                                        
     }                                                                                                                                                                                                          
                                                                                                                                                                                                                
     // Same type and pattern = likely duplicate                                                                                                                                                                
     if (existing.type == stream.type &&                                                                                                                                                                        
         existing.source_pattern == stream.source_pattern) {                                                                                                                                                    
                                                                                                                                                                                                                
       // For DOM streams, check URL too                                                                                                                                                                        
       if (stream.type == StreamType::DOM_MUTATION) {                                                                                                                                                           
         if (existing.url == stream.url) {                                                                                                                                                                      
           return stream_id;                                                                                                                                                                                    
         }                                                                                                                                                                                                      
       }                                                                                                                                                                                                        
       // For network streams, pattern is enough                                                                                                                                                                
       else {                                                                                                                                                                                                   
         return stream_id;                                                                                                                                                                                      
       }                                                                                                                                                                                                        
     }                                                                                                                                                                                                          
   }                                                                                                                                                                                                            
                                                                                                                                                                                                                
   return std::nullopt;                                                                                                                                                                                         
 }                                                                                                                                                                                                              
 ```
